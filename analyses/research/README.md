## Place for Research scripts

**Qualification**
- Used to help generate anything presentable to the team to help explore research questions but not yet contributing to a new simulator feature.

**Folder Structure**

Save the script under the appropriate component folder (e.g. `user_model/`), create new folder(s) as needed.

**Content Requirement:**
- The question we are asking
- Results (qualitative/quantitative)
- The conclusion
