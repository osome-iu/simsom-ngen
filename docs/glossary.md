# Glossary

This document serves to establish the lexicon of domain specific vocabulary used in the Social Media Simulator

- Active User
  - A user that can perform actions throughout the simulation.
  - Active users may not always perform actions on every tick of the simulation.
  - Users with `activity_level > 0.0` are active for worker selection.
- Action
  - An event that is triggered by a user
  - Examples include Posting, Reposting, Liking, replying, and quoting.
  - Some actions (updating profile, following/unfollowing) may not be visible to other users.
  - Viewing a post is not considered an Action
- Clock
  - See Global Clock
- Clock Extension
  - A PostgreSQL extension that defines the custom clock functions used to
    allocate `timestamp`.
- Controller Process
  - A process that sets up the database and terminates the simulation based on specified conditions.
- Creator
  - The user who has created an action.
- Database
  - A central store of Users, Actions, and the Follower Network.
  - Currently uses PostgreSQL
- Feed
  - A Recsys-sorted list of Actions that are shown to a User
  - For example, Posts, Replies, Quotes, and Reposts, but not Likes
- Follower
  - A User that follows a given User.
  - A user cannot make another user follow them.
- Follower Network
  - A directed network of Users indicating who follows who
  - The direction of the edge goes from a Follower to a Friend
  - Information will go from a User to its Followers
  - When forming a feed of a user, we consider the posts by the user's Friends
- Friend
  - A User that is followed by a given User.
  - User1 can follow User2. User2 becomes a Friend of User1. User1 becomes a Follower of User2.
- Global Clock, Database Clock, Simulator Clock, or simply Clock
  - A global counter defined in the Database that is used to set an Action's
    `timestamp`.
  - Ensures that no two actions have the same simulator timestamp (min
    difference of 1 ms).
  - Uses a sequence-backed increment-by-1 fallback or the `simsom_clock`
    distribution-backed allocator when the extension is enabled.
- Lurker
  - A user with `activity_level == 0.0`.
  - Zero-activity users do not perform actions.
  - They can still contribute action view counters when selected for
    a worker batch.
  - The default simulator config uses `setup_db.lurker_ratio = 0.169` as the
    initialization ratio for exact-zero activity levels.
- Moderation Policy
  - The set of rules and algorithms that the Policy Process uses to interact with users and posts
- Original Post
  - A new post that a user has created that does not reference a previous post
- Parent Post
  - The original Post that a Quote or Repost refers to.
- Policy Process
  - A process that acts upon users and posts to simulate a platform's moderation function.
  - Flags Users and Posts in the Database based on defined rules.
- Post
  - A piece of content generated by a User
- Process
  - A computational process running on a machine.
- Quote
  - A post that both references an original Post and also contains new content.
- RecSys, Recommender, Recommender Algorithm, or Recommender System
  - A platform's algorithm for generating a User's Feed
- Repost
  - A post that references an original Post, but does not contain new content.
- Timeline
  - Time sorted list of Actions taken by a user
  - For example, Posts, Replies, Quotes, and Reposts, but not Likes
- User
  - A simulated user or account on a social media platform
- User Model
  - Function that takes in the User Object and the Feed and generates the user behavior (actions).
- User Object
  - A collection of parameters that inform the User Model.
  - May include information such as user type, activity level, probability of various actions, avg. quality, Vector Profile, scrolling probabilities, etc.
- Vector Profile or User Vector Representation
  - A vector representation of a user's preferences based on timeline of posts, reposts, etc.
- Views
  - The number of times that a post has been viewed by users other than its creator.
- Worker Process
  - A process that simulates a user's interaction with the system
