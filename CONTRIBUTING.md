# Contributing

> [!NOTE]
> We are not currently accepting/merging Pull Requests from outside contributors.  This will change in the future when a better contribution workflow has been developed.

This document provides links to development guidelines and standards that should be followed if contributing to this project.  Most documentation pertaining to development policies and standards can be found in the [./docs/development directory](./docs/development).


Instructions regarding branching, merging, and pull requests can be found in [./docs/development/git_branching.md](./docs/development/git_branching.md)
